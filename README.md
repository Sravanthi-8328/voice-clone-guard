# AI-Powered Voice Clone Guard

## Smart India Hackathon 2026

**Problem Statement:** SIH26104  
AI-Powered Real-Time Detection and Prevention of Voice Cloning Impersonation Attacks

## Project Overview

Our system detects AI-generated or cloned voices and assesses the risk of voice impersonation attacks. Based on the detection result, the system can warn, verify, or block suspicious interactions.

## Main Modules

1. AI Voice Deepfake Detector
2. Audio Processing Pipeline
3. Backend API
4. Risk & Prevention Engine
5. Frontend Dashboard
6. Testing & Integration

## Team Workflow

Each team member works on a separate Git branch and module. All completed modules are integrated and tested before merging into the main branch.
